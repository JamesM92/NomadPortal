# Pinned dependencies for reproducible Docker builds.
#
# The Reticulum stack (rns / lxmf / nomadnet) ships frequently with tight
# inter-package version constraints. The versions below are a known-good
# mutually-compatible set — verify with `pip install -r requirements.txt`
# in a fresh venv before bumping any of them.

# Reticulum stack
# Pinned to the pre-v0.9.24 set (2026-06-05): the rns 1.1.3 → 1.3.x +
# lxmf 0.9.4 → 1.0.x + nomadnet 0.9.8 → 1.2.x bump silently broke
# inbound link establishment to hosted NomadPortal sites. Under 1.3.x
# rns, clients see the announce, the link request lands at the host
# and gets accepted, then times out at "waiting for RTT packet from
# link initiator" while logs flood with "No interfaces could process
# the outbound packet". Setting enable_transport=true didn't fix it.
# Intermediate revert to rns 1.2.9 (May 2026) broke announces entirely
# (lxmf/nomadnet pins were incompatible), so the whole stack is rolled
# back to the last known-good coherent triple from before the v0.9.24
# Dependabot batch. Don't rebump these together without confirming
# the link-handshake behaviour in an isolated test deployment first.
rns==1.1.3
lxmf==0.9.4
nomadnet==0.9.8
