This is the first start, so there is no admin account yet. To prove you run this server, open the file admin_setup_code in the config directory (for Docker: docker exec <container> cat /config/admin_setup_code) and type the code it holds. The file is deleted when you finish.

Forgotten later? There is no email reset. Run python -m nomadnet_web.admin_cli reset-password inside the container.

This web interface is not a hardened or secure way to access LXMF. Site administrators may have access to your messages and private information. It is intended primarily to provide clearnet access to a NomadNet site. For private communications, use a dedicated LXMF client directly.
