Identities & Fingerprints
⚠ Back up config/reticulum/identities/ regularly. These files contain RNS private keys. If the volume is lost or the container is destroyed without a backup, all user LXMF addresses are permanently gone and cannot be recovered.

Each user account has one RNS identity, created automatically on first use. Identities are only revealed when you explicitly send a fingerprint to a node — browsing is always anonymous. Resetting regenerates the keypair; the old identity cannot be recovered.
