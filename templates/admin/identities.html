Identities & Fingerprints
⚠ Back up config/reticulum/identities/ regularly. These files contain RNS private keys. If the volume is lost or the container is destroyed without a backup, all user LXMF addresses are permanently gone and cannot be recovered.

Each user account gets an RNS identity automatically on first use, and can create more from Settings → Identities — one is "active" at a time for sending/announcing, but every identity an account owns can still receive messages. Identities are only revealed when a user explicitly sends a fingerprint to a node — browsing is always anonymous. Resetting regenerates the keypair; the old identity cannot be recovered.
